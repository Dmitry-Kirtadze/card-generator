# Генератор карток товарів

Десктопна програма (Python + PySide6) для пакетного створення карток товарів
за шаблонами: редактор шаблону → таблиця даних → попередній перегляд → експорт JPEG.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

У VS Code: відкрити папку, F5 → «Запустити програму».
Тести: `.venv\Scripts\python -m pytest` або вкладка Testing у VS Code.

## Програма й установник

```bash
.venv\Scripts\python tools\build_exe.py --install
```

Збирає програму (`dist\CardGen`) і установник `dist\Встановити Генератор карток <версія>.exe`
(Inno Setup 6: `winget install JRSoftware.InnoSetup`). Установник — один файл, який можна
надіслати іншій людині: ставить програму в `%LOCALAPPDATA%\Programs\CardGen` без прав
адміністратора, з ярликами на Робочому столі й у меню «Пуск», видаляється через
«Установлені програми». З `--install` — ще й встановлює на цей комп'ютер.

Як влаштовано (`launcher.py`): .exe містить Python, бібліотеки й початкову копію коду.
Оновлений код програма сама завантажує з GitHub у `%LOCALAPPDATA%\CardGen\app`
(git для цього не потрібен) і запускає його; поки його немає (або він потребує новіших
бібліотек) — працює вбудований код. Журнал: `%LOCALAPPDATA%\CardGen\cardgen.log`.

Перезбирати установник потрібно лише тоді, коли змінюються бібліотеки: тоді збільшити
`RUNTIME` у `cardgen/__init__.py` — старі встановлення продовжать працювати на своєму коді
й попросять встановити нову збірку.

## Оновлення

Нова версія = коміт у гілці `main` на GitHub (репозиторій публічний, вхід не потрібен).

- під час запуску програма у фоні перевіряє GitHub; якщо увімкнено «Встановлювати оновлення
  автоматично» (типово — так), сама завантажує зміни й пропонує перезапуститися;
- кнопка **«Оновлення…»** на головному екрані — перевірити й встановити вручну;
- запуск з git-копії (розробка) оновлюється через `git pull`, а якщо змінився
  `requirements.txt` — бібліотеки доставляються автоматично; якщо файли змінено вручну,
  оновлення зупиняється, щоб не стерти ці зміни;
- дані користувача в код не входять і оновленням не зачіпаються.

## Маркет

Вбудована категорія готових шаблонів — її не можна видалити чи перейменувати. Шаблони
копіюються в будь-яку категорію кнопкою «Скопіювати в категорію…», свої — додаються
кнопкою «Додати в Маркет». Пакети шаблонів лежать у `market/*.cardgen.zip` і під час запуску
автоматично з'являються в Маркеті. Перезібрати їх: `.venv\Scripts\python tools\build_market.py`.

## Де зберігаються дані

`Документи\Генератор карток` (зібрана програма) або `workspace/` поруч із main.py (розробка).
Змінити: `"workspace"` у `%LOCALAPPDATA%\CardGen\settings.json` або змінна `CARDGEN_WORKSPACE`.
Структуру описано на початку `cardgen/storage.py`.

## Структура коду

- `cardgen/model/` — блоки, шаблон, категорія; збереження у JSON з версіями формату
- `cardgen/storage.py` — категорії, шаблони, таблиці даних, бібліотека, кошик
- `cardgen/transfer.py` — експорт/імпорт категорії файлом `.cardgen.zip`
- `cardgen/data/` — схема полів, дані товарів (`tables/data.json`, фото в `tables/images`),
  перевірка, імпорт/експорт Excel і CSV, фото з Excel / за іменем файлу / за посиланням
- `cardgen/generate.py` — картка = шаблон + дані + ручні правки товару (`tables/overrides.json`)
- `cardgen/products.py` — товари шаблону: відмальовування, «зберегти для товару / для шаблону»
- `cardgen/export.py` — експорт JPEG: маска імені файлу, профіль «Пром і Розетка»
- `cardgen/render/` — рушій відмальовування (спільний для редактора й експорту)
- `cardgen/ui/` — інтерфейс; `cardgen/ui/editor/` — редактор шаблону
- `tests/` — автоматичні тести; `tests/golden/` — еталонні зображення
  (оновити: `UPDATE_GOLDEN=1`, після чого переглянути їх очима)

## Гарячі клавіші редактора

| Клавіші | Дія |
|---|---|
| Ctrl+Z / Ctrl+Y (Ctrl+Shift+Z) | Скасувати / повторити |
| Ctrl+C / Ctrl+X / Ctrl+V | Копіювати / вирізати / вставити |
| Ctrl+D | Дублювати |
| Ctrl+A | Виділити все |
| Ctrl+G / Ctrl+Shift+G | Згрупувати / розгрупувати |
| Ctrl+] / Ctrl+[ | На шар вище / нижче |
| Ctrl+Shift+] / Ctrl+Shift+[ | Нагору / донизу |
| Delete | Видалити |
| Стрілки (Shift — ×10) | Зсунути на 1 px |
| Ctrl+' | Показати / сховати сітку |
| Ctrl+S | Зберегти зараз |
| Esc | Зняти виділення |
| Ctrl + коліщатко / пробіл + миша | Масштаб / рух полотна |
| Shift під час руху / повороту / розміру | Лише по осі / кроком 15° / змінити пропорції |
| Alt під час руху | Без прилипання |
| Подвійний клік по блоку групи | Вибрати окремий блок |
